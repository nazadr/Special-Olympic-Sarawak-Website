📋 Quick Start Testing

Prerequisites:
  • XAMPP running (Apache + MySQL)
  • Browser developer console open (F12)
  • Logged into admin panel
  • At least one news article exists for testing edit function

🎯 Test Scenarios

Scenario 1: Add New News Article

Click "Add News" button in News section
Verify modal opens with title "Add New News Article"
Verify submit button shows "Add News Article"
All form fields are empty
Fill in: Headline, Date, Description, and upload an image
Click submit and verify success message
Modal closes automatically
New article appears in the list

Scenario 2: Edit Existing News Article

Click the edit button (pencil icon) on any news article
Verify modal opens with title "Edit News Article"
Verify submit button shows "Update Article"
All form fields are populated with existing data
Image preview displays the current image
Modify the headline
Click submit and verify "updated successfully" message
Changes are reflected in the article list

Scenario 3: Edit with Image Replacement

Click edit on an article with an image
Current image displays in preview
Click "Choose File" and select a new image
New image preview replaces the old one
Submit the form
Verify new image displays in article list
Check uploads folder - old image should be deleted

Scenario 4: Modal State Reset

Open edit modal for an article
Verify data is loaded
Close modal without saving (click X or Cancel)
Open "Add News" modal
Verify all fields are empty (not showing edit data)
Verify title shows "Add New News Article"
Verify button shows "Add News Article"

🐛 Issues Fixed

CRITICAL Data Fetching Issue

Problem: Edit button used incorrect DOM selectors, causing data to not load properly.

✓ Solution: Implemented server-side data fetching with new fetch_single endpoint. Data now loaded accurately from database.

MODERATE Modal State Management

Problem: Same modal used for Add and Edit without proper state tracking.

✓ Solution: Added data-mode attribute, created separate openNewsModalForEdit() and resetNewsModal() functions.

MODERATE Form Submission Logic

Problem: Form always sent action=add regardless of mode.

✓ Solution: Dynamic action determination based on newsId field presence.

CRITICAL Backend Field Mismatch

Problem: Frontend sent currentImage but backend expected currentImagePath.

✓ Solution: Frontend updated to send currentImagePath matching backend expectations.

🔍 Debug Tips

⚠️ If something doesn't work:
  1. Open browser console (F12) and check for JavaScript errors
  2. Check Network tab to see API requests/responses
  3. Verify file permissions on assets/images/news_uploads/ folder
  4. Check PHP error log in XAMPP
  5. Clear browser cache and reload page
